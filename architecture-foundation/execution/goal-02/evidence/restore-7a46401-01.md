This run is retained for diagnostic and audit continuity, but it is not accepted
evidence and is not referenced by the evidence index. Independent review found
that its 6,158 ms RTO subtracted `Date.now()` values across processes. A wall or
NTP step could therefore distort the required elapsed-time measurement, contrary
to the frozen monotonic-clock contract. Run `restore-a517cf3-01` supersedes it
after a new exact-source execution with a single monotonic timing boundary.

   receipt-backed Usage entry and one object.

   checksum-bound object manifest and complete marker. The source container,
   network and volume were then removed.

   tables before restore.
4. The production restore function restored the database and object. Runtime
   grants were re-established through the normal runtime-role initializer.
5. A fresh process compared deterministic checkpoint digests, verified RLS and
   confirmed the usage history still rejected mutation.
6. The target container, network and volume were removed; no validation Docker
